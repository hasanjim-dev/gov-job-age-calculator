# Government Job Age Calculator 🇧🇩

A web-based Government Job Age Calculator designed to help users calculate their age and check government job age eligibility in Bangladesh.

## 🌐 Live Demo

**Live Website:**
https://gov-job-age-calculator.vercel.app

## 🚀 Features

* Calculate current age using date of birth
* Calculate age in years, months, and days
* Check government job age eligibility
* User-friendly interface
* Responsive design for desktop and mobile devices
* Simple and easy-to-use age calculation system
* Instant calculation results

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* React.js
* Vite

## 📌 Project Purpose

The purpose of this project is to create a simple and useful tool for people in Bangladesh to calculate their current age and check government job age eligibility based on their date of birth.

This project was developed as a practical web development project to improve skills in React.js, JavaScript, UI design, and responsive web development.

## 💻 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/hasanjim-dev/gov-job-age-calculator.git
```

### 2. Open the project folder

```bash
cd gov-job-age-calculator
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the local URL

Open the URL shown in the terminal, usually:

```text
http://localhost:5173
```
